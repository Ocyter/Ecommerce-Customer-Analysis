# Data

The raw `ecommerce_customer_data.csv` file is intentionally not committed to the public repository.

## Expected columns

`User_ID`, `Gender`, `Age`, `Location`, `Device_Type`, `Product_Browsing_Time`, `Total_Pages_Viewed`, `Items_Added_to_Cart`, `Total_Purchases`

## Run locally

Place the CSV in the project root as `ecommerce_customer_data.csv`, or launch the Streamlit app and upload the CSV through the sidebar.

The dashboard is designed to work from the uploaded dataset without exposing customer-level data in the public repo.

## Source and verification status

The original 500-row CSV is not published. The repository does not document its
original provider, licence, observation period or whether it is real or simulated.
The existing figures are retained as published portfolio results; this update
does not independently rerun them. Missing-value and duplicate-check outcomes
are not supplied. Full verification needs the original file and its provenance.
These are sample descriptions, not employer outcomes or evidence of an uplift.
